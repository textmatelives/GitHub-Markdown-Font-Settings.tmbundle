# GitHub-Markdown-Font-Settings.tmbundle
Provides a location to set fonts for the [GitHub Flavoured Markdown for TextMate bundle](https://github.com/textmatelives/GitHub-Markdown.tmbundle).

## Features
- By default it uses Menlo 1.0em so that line wrapping works correctly.
- Use Menlo for the Markdown editor monospaced text font and 95% size.
- Uses the default font size for the Markdown editor hash/pound prefix to make it less prominent.
- Markdown headings have relative sizes similar to those used in preview.

*Note*: If you use a proportional font (e.g. San Francisco), word wrap in TextMate Lives (optimized for mono character columns) will be off, and either "shy" of the wrap column, or extending beyond the wrap column by several characters.

## Installation
Check "Markdown (GitHub) Font Settings" in TextMateLive's "Bundles" Preferences dialog.
